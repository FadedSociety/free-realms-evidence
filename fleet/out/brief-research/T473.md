**Risks and corrections:**
1. **Hub claim is false.** The brief says "no hub file", but `encounter.rs` is a capped hub (`tests/spine_rules.rs:9-12` HUBS includes `src/encounter.rs`, headroom 40). The composite_effect visibility change touches it. Keep the diff to one `pub(crate)` token.
2. **build_effect_tag conflict.** The brief calls `build_effect_tag(buff_id, ...)`. That function writes the tag id into both TagId and `unknown_2` (definition id, abilities.rs:931). A buff id would become the definition id. The builder needs a definition-id parameter or a direct `effect_packets` call. After T472, `unknown_1` also becomes the instance id, so the 38/16 row must carry the buff id in both instance and tag.
3. **Expiry order.** The brief sends 35/15 + 38/17 before the aura resync. Sanctuary resyncs right after 35/15 and before 38/17. Pick one and test it; the brief's order is a choice, not a client requirement (R).
4. **Delay semantics.** The brief does not say whether the 38/16 remaining time includes `delay_ms`. Sanctuary includes it. Decide before the wiring brief.
5. **Scale revert** is 1.0 in the brief; Sanctuary reverts to another effect's scale or DefaultScale 1f (`Player.cs:126`). Consistent for a single scale.
6. **Lead-only:** none touched directly, but the 38/16 rows are session-visible. Mounted-player behaviour is unverified until native testing.
7. **T472 must merge first**, or the 38/16 instance id is 0 and the buff bar collapses rows.
