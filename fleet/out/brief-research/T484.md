**Risks and corrections:**
1. **False claim: T380 is not "flag 1 for every listing".** It sends an **empty** 66/39 list (coin_shop.rs:1134), and T380.md:58-60 rejects per-listing flags because 66/5 already sends 0. The brief's (a)/(b) change the wire shape.
2. **Pinned test breaks:** tests/coin_store_siblings.rs:1488 pins `[66,0,39,0,0,0,0,0]`. The brief says "T380's test stays green", which is wrong for gate (a). Update it, do not loosen it.
3. **T453 is not on the tip.** `order_packet` (:544) writes result first. Gates (b)-(d) decode tracking first. Merge T453 before this build, or (b) fails on the second order.
4. **T229 and T429 are not merged.** There is no `src/gameplay/sc_earnings.rs` and no `rides_tradeable`. The lead note's "replace `bought_ride_catalogue_row_is_no_trade`" has no target yet. Leave that test alone.
5. **Ownership key mismatch.** The brief's `owns_item` checks the listing item id. Mount ownership (mounts.rs:213-221) checks `item_definition_id_candidates`. A ride whose candidates differ from its listing id would show as owned on 168/5 but buyable in the shop, or the reverse. Reconcile the two.
6. **Rental items:** `owns_item` must say whether a rented instance counts (R). Grants never stack onto rentals.
7. **Hubs:** none of station_cash.rs, coin_shop.rs or inventory.rs is a capped hub. No signature change is needed for `handle_marketplace`.
8. **Lead-only / other:** the brief's rule that a traded ride is buyable again is correct only on the order path. The client flag updates on the next store open.
