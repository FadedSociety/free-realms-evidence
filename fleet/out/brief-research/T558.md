**Risks and corrections:**
1. **Schema replacement.** `Effects::load` replaces the whole default table with `consumables.json` (`item_bar.rs:126`). A data file that omits 2173 and 11002 silently removes the Small Health Potion. Include both rows.
2. **Validation rejects 48104.** `Effects::new` requires `use_wire::consumable(definition)` (`item_bar.rs:97`), which only knows the seven piece_046 rows. Adding 48104 means editing `restoration/piece_046.rs`, which is outside the brief's owners.
3. **Cooldown bound.** `MAX_COOLDOWN_MS` is 600,000 (`item_bar.rs:52`, checked at `:96`). A 3,600,000 cake cooldown must not go through that `Effect` validation. Keep it on the placed-cake row.
4. **New kind.** `random { outcomes }` is a new kind. `EffectFile` uses `deny_unknown_fields` and `schema_version` 1 (`item_bar.rs:56-69`), so this changes the schema.
5. **"Never repeats" is only "not the last outcome".** With five equal outcomes, the roll excludes one and picks from four. The gate must test "not equal to the previous roll", and the brief should say so.
6. **Per-player state.** "Last outcome on the item bar" needs a per-character key. `ItemBar.last_used` is keyed by definition (`item_bar.rs:157-159`), which is not per-outcome. Check that `ItemBar` is per character.
7. **Hub growth.** `gameplay.rs` (5,475 lines) and `encounter.rs` are capped hubs. `composite_effect` must be exposed in `encounter.rs` (T473), and that is a hub edit.
8. **Lead-only areas.** The gift and click routing lives in the T557 gateway path (`SharedWorld`, `osfr-gateway.rs`). Do not touch it from T558 without a lead decision.
