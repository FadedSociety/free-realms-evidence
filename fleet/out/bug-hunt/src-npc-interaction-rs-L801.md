- **Encoders (`encode_dialogue_26_3`, `encode_quest_offer_49_1`, `encode_merchant_list_66_42`, `encode_merchant_buy_66_43`):** size and count limits are checked before writing. Nothing is mutated before a `?`, so there is no atomicity problem here.

The `zone_id` and `position` are supplied by the server from `character.zone_id` and `character.position` (gameplay/npc.rs:432-433 and 812), not from the packet. The zone-0 pass-through is the documented regional-label design, and the distance check still applies.
- **`build_options` / `interaction_list_packet` / `merchant_window` / `dialogue_context`:** the option count is capped at `MAX_MENU_OPTIONS` with an error return. Name length is capped. Quest options are filtered to `QuestStatus::Active` and deduplicated. Vendor items are looked up only through the server's `vendor_items` and `prices` maps. The inputs are content, not client packets.
