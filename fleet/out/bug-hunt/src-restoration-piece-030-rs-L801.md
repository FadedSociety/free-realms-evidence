- **[medium] prototype/osfr-tools/src/restoration/piece_030.rs:1025 - `evaluate_restart` counts fixtures placed at any sequence number, not only those placed before the restart marker, so the Restart gate can pass with no pre-restart placement.**
  - Failure scenario: a transcript is `EnterRequest`(owner, seq 1), `ZoneData`(seq 2), `ServerRestart`(seq 3), `PlaceFixture`(F, seq 4), `InstanceData`(house, seq 5, lists F). The code takes `restart` = seq 3. `placed` (line 1025) counts F, so the "no fixture was placed before the restart" Unproven branch (1026-1030) does not fire. `expected` (1031-1035) is built from all placed fixtures, and F has no position update, so `expected_position` is `None` and the position check is skipped.   - Reach: `evaluate_transcript` (511) → `evaluate_gate` (659-661) → `evaluate_restart`. The rows come from a capture supplied to `evaluate_transcript` (the replay caller is at 1460). Nothing upstream filters by `seq > restart.seq`; `validate_rows` (527-585) only checks ordering, opcodes and house guid.
  - Fix: restrict both the `placed` count and the `expected` map to facts with `place_seq < restart.seq`, e.g. have `collect_fixtures` only take rows before `restart.seq`, or add `.filter(|f| f.place_seq.is_some_and(|p| p < restart.seq))` in both places.
