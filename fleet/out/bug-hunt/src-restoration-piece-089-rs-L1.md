Outer 5 and flag 0 pass. `inner_length(2) == 9-7` passes on line 202. `opcode = bytes[7..9] = 40` passes on line 206. Line 209 then evaluates `bytes[9]`, which is past the end of a 9-byte slice, so the process panics. A 10-byte frame panics the same way on `bytes[10]`.

This is latent, and it becomes a remote crash as soon as the module is wired in. Downgraded to medium for that reason.
