# Sunstone Jones (Sanctuary)

**NPC:** 9500000537, Sunstone Jones, Sanctuary (treasure-hunt host, Lost Treasures Month; gives Scrap Collector).

**Greeting:** `locale 5102580`: "There's treasure out there for the taking. Trust me. There's just one thing...  you'll need a map.<br><br>Rumor has it combat encounters reward secret treasure map scraps when completed. So why don't you go completed some and see what you find?"

This is the first line Jones speaks when the player comes to him to start Scrap Collector. It is the opening speech of the quest, not a generic greeting, so it is the best-supported choice, but it is a quest line rather than a standing "hello".

**Proof (rule 1, wiki quote attributed to this character):** `refs: freerealms-wiki/quest-pages.json` (Quest:Scrap Collector, wiki revision 35279, 2013-11-15). Under "Steps", the text reads: "Speak with Sunstone Jones located in Sanctuary." followed by the quoted line "There's treasure out there for the taking. Trust me. ..." and then "-Sunstone Jones". The same page attributes the later line "Nice work, kid. Now you need someone with the brains to assemble these scraps..." (locale 5102584) to "-Sunstone Jones". The page also states "To Start: Speak with Sunstone Jones located in Sanctuary during Lost Treasures Month."

Supporting context: `repo: notes/Build Guides/Content/NPCs/NPCs - Sanctuary.md:145` lists Sunstone Jones with role "Scrap Collector (daily; client 657220927)". The repo's NPC file `prototype/osfr-tools/data/content/npcs/sanctuary.json:57202-57235` has no greeting string id bound to him.

**Checked and rejected:**
- `locale 5102584` ("Nice work, kid. Now you need someone with the brains...") is also attributed to Jones by the wiki (rule 1), but it is the mid-quest return line, not his opening line. Kept as an alternate.
- `locale 5102581` ("I understand Jones sent you? ...") is spoken by Kara Loft, so it is not his line.
- Other "treasure"/"scrap" strings (e.g. 5102585 "Kara Loft", 5102586 "Find Kara Loft", the Sunstone Valley Scrap Collector Flashbang lines) do not name Jones as speaker.
- `notes/Build Guides/Content/NPCs/NPCs - Sunstone Valley.md:179` says Jones is not a Sunstone Valley NPC, so no Valley line applies to him.
- No quest JSON in `repo` contains the Scrap Collector intro text id, so rule 3 could not be confirmed from data. Rule 1 is the proof used here.
