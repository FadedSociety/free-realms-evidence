# Quests of Aster (Wilds)

## Summary

Aster (npc 9000000243, Wilds) gives three quests. All three already exist as **skeleton records** in `prototype/osfr-tools/data/content/quests/warrior.json` (ids 3150010, 3150012, 3150013; `giver_npc_id` 9000000243; `enabled: false`). Each has a title, intro, description and end-text string id, plus source evidence. But `objectives` and `rewards` are empty, so no steps are built. The record's `quest_ids_given` lists only 3150010, which is stale. The dossier below supplies the missing steps and targets for the two unbuilt parts. Nothing new is invented.

Numeric ids in the record for objectives (3906118291, 3815545278, 1811945937, 2039252240) are **not** `locale` string ids. They are the `ucdt` hash keys in the client's `en_us_data.dat`, as cited in `Jobs/Warrior.md`. The `locale` tool returns "no such id" for them. The string ids below come from `locale`.

## Gaps

- **Skeletons exist but are not built.** `objectives` and `rewards` are empty in all three, and `enabled` is false. The record's `quest_ids_given` only lists 3150010. Quest ids 3150012 and 3150013 are batch keys (R), not numeric server ids.
- **Record ids are not locale string ids.** 3906118291, 3815545278, 1811945937, 2039252240, 313739159 resolve only as ucdt hash keys in the client dump. Their string-id equivalents (71264, 72613, etc.) were found by text match.
- **Kill counts** for Thugawug Sneaks and the Bumbler are not evidenced. Enemy ids are not resolved in `client` Resources.
- **Rewards:** only the W12 Pro Warrior Hammer (wiki) and an unreadable video banner. Level 10 and Ankle rewards: unknown.
- **Completion line** for the ankle quest (72613) is an injury complaint, not a clear turn-in. The return step is inferred.
- **Second Knocking stage** (toll-booth token, Thugamug boss) is wiki and video only, with dagger-level evidence, and is not in the record.
- **Wiki** has no pages for these quests; the only sources are `Jobs/Warrior.md` and the client locale.
