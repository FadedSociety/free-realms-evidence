**Scope.** Chase gives three quests, the Kart Driver series: Making Amends, High Speed Chase and Sweetwater Sasparilla Sponsorship. The record's `quest_ids_given` lists only 3080029. The other two are in `quests/kart_driver.json` as stubs (3080027, 3080028) with `objectives: []`, `rewards: []`, `enabled: false`, so I treat all three as unbuilt. ## Gaps

- **Giver conflict.** `kart_driver.json` gives High Speed Chase (3080028) and Making Amends (3080027) giver `9000000271`. That id appears only in `npcs_unresolved.json:1979–1990` as a duplicate "Chase Wheeler [wiki Chase Wheeler]" ref with no resolved zone. Chase's real record is 9000000273. The builder should set all three quests to 9000000273 or merge the refs.
- **Guide ids are not locale ids.** Numbers in parentheses in the guide (for example "3635590744", "3922046495", "2551228779") return "(no such id)" from the locale tool. They look like string hashes (the wilds.json note cites JenkinsLookup2 for 394709). Only the 394xxx/3xxx ids from stubs and text searches are used above.
- **Wrong stub text ids.** High Speed Chase stub description 3533 and end 3534 are unrelated locale strings. Fix them to 394707 and 394708 (intro 394705 is an (R) choice).
- **Sponsorship end text.** 394712 is Shooblemoot's pitch. Whether it is the quest completion or the Shooblemoot talk is not established (R).
- **Rewards.** No reward evidence for any of the three quests (guide: "unknown"; no video coin or XP figures). Lxzxrus/Sanctuary "Making Amends" (QuestId 3033) is a different quest and is not used.
- **Levels, prerequisites by numeric quest id.** Settling the Score = 3080026 (stub), but no numeric quest id is evidenced for the rest of the chain. Level requirements unknown.
- **Steps not confirmed.** Win condition for the High Speed Chase race, trigger for recovering the parts in Making Amends, and whether Sponsorship has an objective-completion step with Shooblemoot are all (R).
- **Locale ids not yet checked.** 395182, 395359 and 398268 are inferred as Making Amends objective lines by text match only; 400946/400947 are unassigned.
