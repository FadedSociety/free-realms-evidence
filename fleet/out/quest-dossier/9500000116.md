# Quests of Cuttensnip (Briarwood)

## Cuttensnip (npc 9500000116, Briarwood / Thistlerow): one unbuilt quest

Only one quest is attributable to her. The "briar thorn" request is Mino Tendersole's (Lakeshore-started, see `npcs/lakeshore.json` ~line 10047), not hers, so it is excluded. No file in `prototype/osfr-tools/data/content/quests/` mentions Cuttensnip, the Snarling Hedges, "Back of My Hand" or the ids below, so nothing is built yet.

Id convention: the `locale` tool numbers (e.g. 17110) are its row indices. The **client keys** (e.g. 4008690113) are the dat-file keys that the guides cite. Both are given where known.

### 1. "Like the Back of My Hand" (fake-wall clearing, The Snarling Hedges)

**Title**
- Locale tool id 17110 = "Like the Back of My Hand". Client key 4008690113 (`ucdt`). The same text also appears as `ugdt` key 1587707681.
- Attribution is by adjacency: 17110 sits directly before the offer text 17111 and the NPC name 17105. Also the Snarling Hedges guide cites 4036011684 for this quest. This is an inference, not an explicit link.

**Giver**

**Steps (in order)**
1. Talk to Cuttensnip in Thistlerow (client 3063425209, "Talk to Cuttensnip in Thistlerow"). The guide's video shows her marker next to Slothi.
2. Accept the quest. Enter The Snarling Hedges (Briarwood maze; dungeon page `notes/Build Guides/Content/Dungeons/The Snarling Hedges.md` lines 83-94).
3. Cut down the budding vines / fake maze walls in the Snarling Hedges: **10** fake walls (client 205112282). The target object ids are not evidenced. A vine golem attacks the player during this, but whether it is a required kill is not evidenced.
4. Return to Cuttensnip and inform her of success (client 3224188757 / 1611077015). The completion line is client 167357172.
