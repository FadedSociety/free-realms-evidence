# Quests of Aunt Daisy (Cobblestone Village)

## Quest dossier: Aunt Daisy (npc_id 9500000244, Cobblestone Village record)

**Correction to the record first.** The quest is listed under Aunt Daisy, but the offer comes from **Ronnie Britesmile** (Merry Vale, name ucdt 1943692833). Daisy is the first objective target, and she sends the player back with a second package. The Lxzxrus community server agrees: its quest has `GiverGuid` and `TargetGuid` 100000002195, which is Ronnie (NPC id 2195). Treat Daisy as a hand-in/objective NPC, not the giver. Ronnie's own record (`npcs/merry_vale.json` ~line 25751) lists this package errand, so the quest should be filed under Ronnie with Daisy as a step.

The record's second id, 832424182, is not a separate quest. It is the return-leg objective of the same quest.
