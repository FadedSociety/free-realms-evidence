- Mongo is the battle target in `quests/brawler.json` (C1 objective 2 uses encounter 12400, lines ~179-190). It is not a giver there.

- No `quests/*.json` file contains a "Battles" quest yet. If a builder wants it, the giver is Chatty, and it needs its own record. It is not a Mongo quest. I did not build it here: the giver's NPC id and the quest's steps are not in the evidence I read.
