# Jojo (npc 9500000312, Greenwood Forest, Summer Camp): unbuilt quest dossier

**Scope.** Jojo's ninja-book chain is Wilds South chapter 3. None of the five quests is in `prototype/osfr-tools/data/content/quests/*.json`. The grep for Jojo and the title hashes there only hits an unrelated Pet Trainer quest, whose title id merely contains "3287". I wrote up the first four, in chain order. Dojo Mojo (dev 3-5) is the fifth and is not written up; its locale strings are listed under Gaps.

**Key finding on the record.** The five hashes in `quests_given_text` (2494369850, 1518704907, 3640780368, 2858199764, 3409500121) are the *dev-label* keys ("SGRevamp - Wilds South - 3-N - ..."), not the player-facing titles. The player-facing title keys are listed per quest below. Both sets are in the client table.

**Evidence sources used throughout:**
- Locale string ids (the `locale` tool), e.g. 441710.
- Locale hash keys from the client table test copy, `refs: FreeRealmsLocaleTools/test/FreeRealmsLocaleTools.Tests/data/en_us_data.dat`, at the line numbers given.

**Chain inference (applies to all four).** The client has no quest table. The chain order comes from the dialogue ids. Each quest's completion line sits at id N+1 of its title, and the next quest's offer line sits at N+3. Example: 441712 is the A-go-go reaction and 441713 opens Mojo, in Jojo's first-person voice. The mapping is consistent across all four quests, but it is inferred and not a server record.
