# Noggle Cogloose (npc 9500000838, name_string_id 440141), Sunstone Valley: unbuilt quest dossier

Noggle gives five quests. None is in `prototype/osfr-tools/data/content/quests/*.json` (a search for the titles and "Noggle" there returned nothing). Four are written up below in chain order. The fifth, Ruined Return, is only sketched under Gaps.

**Quest chain:** Ambush Recovery → Power Crystals Not Included → Noggle Interrupted → Committed to the Plan → Ruined Return. The wiki's Ruined Return page requires Committed to the Plan. The Legendary Sunstone (Rizzle's quest) lists Ambush Recovery as its "next" quest.

**Locale id note:** the `locale` tool uses small sequential ids (e.g. 29649). The `.dat` hash keys in the guide (e.g. 2571485710) are different. Where I cite a hash, I matched it to the locale id by identical text.
