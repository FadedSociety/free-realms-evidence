### Problems with the existing builds (not new quests)

- **Giver ids do not match this NPC.** All six records use placeholder giver ids in the 9000000378–9000000382 and 9000000541 range. `npcs_unresolved.json` (for example line 2815) lists 9000000378 as "Linx Redline [client 1960057046]", so the builder knew the giver was Linx but did not link it to 9500000916. The Wilds NPC record (`npcs/wilds.json:26131`) has no `quest_ids_given` entry for these quests either.
- **Two Linx NPC records exist.** `npcs/briarwood.json:39782` has Linx Redline as 9500000164, and it also lists The Showdown. `notes/Research/NPC Placement.md:73` lists both ids. The builder should decide which id is the real giver.
- **Title spelling.** The built record for Challenging T.R. uses the locale title 'Kart Driver: Challenging T.R.' (394235), which is correct. Its evidence line (kart_driver.json:454) spells it "Challenging T.R" without the final period, so that evidence line is slightly off.

## Gaps

- No quest in this set is unbuilt. Nothing new has been dossiered.
- The intro, objective and completion text ids in the built records were not re-verified line by line in this pass. Only the title ids were checked against the locale.
- No reward data is evidenced for any of the six quests. The built records leave `rewards` empty, and no wiki or community-server reward data was found for these quests.
- No prerequisite is numeric in the built records. The guide gives only narrative order (for example, The Showdown comes after Burnt Rubber).
- The giver mapping in the built records (see above) is unresolved and needs a builder decision.
