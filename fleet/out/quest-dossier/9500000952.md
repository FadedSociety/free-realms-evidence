Tido's record lists four quest titles, "Free Tido", "Free Sola", "Free Mifa" and "Free Dore". None is built in `prototype/osfr-tools/data/content/quests/*.json`. I found the titles and one line per captive in the client text. I found no offer text, objective lines, completion text, steps, prerequisites or rewards for any of them, and no evidence that Tido gives them. I did not write a per-quest dossier for each title, because every one would have the same gaps. The four are treated as one group below.
