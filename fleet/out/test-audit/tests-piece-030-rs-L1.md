- **[medium] tests/piece_030.rs:257 native_capture_origin_is_the_only_route_to_complete_evidence - the name claims that NativeCapture is the only route to complete evidence, but the test only evaluates with NativeCapture and checks that the result is NativeCapture.**
  - Why it cannot catch a regression: `evaluate()` (test line 96) hard-codes `EvidenceOrigin::NativeCapture`, so `native.origin == NativeCapture` restates the input. `native_evidence_complete()` is `origin == NativeCapture && is_evidence_complete()`.
